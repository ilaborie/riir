Rust Vs langages à gestion de mémoire

Autres avantages

  • Types de données algébriques, trait
  • Pattern matching
  • Option et Result

🔑 Propriété et emprunt

  • T : transfert de propriété (move)
  • &T : emprunt partagé — &mut T : emprunt exclusif

Une seule règle : plusieurs lecteurs, ou un seul écrivain. Jamais les deux.

🧵 Fearless concurrency

  • Send : transférable vers un autre thread

  • Pas de data race, à la compilation

5.2 Comment RIIR ?

Comment RIIR ?

🧗 Par composants

Un composant à la fois — Firefox, RediSearch

🤖 Traduction automatique

  • c2rust : transpilation à base de règles
  • DARPA TRACTOR : Translating All C To Rust

🏗️ Trois échelles

  • une dépendance — Google, giflib : perf neutre, millions de tests
  • tout le code — Bun : 535 000 lignes Zig → Rust en 11 jours
  • une réimplémentation — pgrust : Postgres, 46 066 tests (pas pour la prod)

⚠️ Deux pièges

  • le unsafe : un port mécanique = du C déguisé en Rust
  • l'oracle : écrire le Rust n'est plus le goulot, prouver l'équivalence l'est

5.3 Et notre CVE ?

🗺️ Et notre CVE GDAL ?

❌ Non, on ne réécrit pas GDAL

C++, 200+ formats, 25 ans de corrections de bugs

🎯 Le bug n'est pas dans GDAL, mais dans un zlib embarqué

🛠️ Réduire le périmètre

  • mettre à jour — GDAL ≥ 3.11.0
  • isoler — sandbox, WASM
  • remplacer le composant C — zlib-rs : memory-safe et le plus rapide

📉 Écrire le neuf en Rust

Android : 76% → 24% des vulnérabilités mémoire (2019-2024)

sans réécrire l'ancien code — en géo, GeoRust

On n'a pas besoin de RIIR de tout.
Il faut RIIR ce qui compte.
